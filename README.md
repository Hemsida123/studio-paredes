# Studio Paredes – komplett webbplats

Paketet innehåller 22 färdiga sidor, lokala bilder, typsnitt och alla tillhörande filer. Ingen installation eller byggprocess behövs.

## Ladda upp på GitHub Pages
1. Packa upp ZIP-filen.
2. Lägg index.html, övriga HTML-filer, styles.css, script.js, favicon.png, robots.txt, sitemap.xml och mappen assets direkt i ditt GitHub-repository. Lägg inte en extra mapp runt filerna.
3. Öppna Settings → Pages. Välj Deploy from a branch, main och /(root). Spara.
4. Vänta tills publiceringen är klar och öppna adressen som GitHub visar.

Filnamnet måste vara exakt index.html. Alla länkar och bilder använder relativa sökvägar och fungerar också under en GitHub-projektadress.

## Kontakt och bokning
Bokningsknapparna länkar till Studio Paredes befintliga Google-kalender. Kontaktformuläret öppnar ett mejlutkast; besökaren skickar själv från sitt e-postprogram. Kopiering fungerar på HTTPS eller localhost. Inget formulär skickas via en dold server.

## Publiceringsadress och SEO
Metadata och sitemap.xml använder den nya förhandsvisningsadress där webbplatsen publicerades. Vid flytt till GitHub eller företagets egen domän: ersätt https://studio-paredes-arkitektur.carlzzon121.chatgpt.site i HTML-filerna, robots.txt och sitemap.xml med den fullständiga nya basadressen, inklusive eventuell repository-sökväg.

## Innehåll
Fakta, kundomdömen, porträtt och projektbilder hämtades från https://paredes.se/ den 1 oktober 2026. Projektvisualiseringar är märkta som sådana. Inga betyg eller recensionstal har hittats på. Guidernas länkar leder till arkitektens befintliga artiklar.

Bildmaterialet tillhör Studio Paredes och används för presentationen av deras verksamhet. Typsnittens licenser ligger i assets/licenses.
